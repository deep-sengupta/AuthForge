# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and collaborative environment for everyone participating in the AuthForge community.

We expect contributors, maintainers, and participants to communicate professionally and treat others with respect, regardless of background, experience, identity, or level of expertise.

## Expected Behavior

Examples of positive behavior include:

- Being respectful and constructive in discussions and reviews.
- Welcoming different perspectives and technical approaches.
- Giving and accepting feedback in good faith.
- Focusing criticism on ideas, code, and behavior rather than people.
- Respecting privacy and sensitive information.
- Helping create an environment where contributors can participate without harassment.

## Unacceptable Behavior

Examples of unacceptable behavior include:

- Harassment, intimidation, discrimination, or personal attacks.
- Abusive, threatening, or deliberately disruptive language.
- Publishing another person's private or sensitive information without permission.
- Repeatedly dismissing or derailing good-faith contributions.
- Trolling, targeted harassment, or sustained hostile behavior.
- Encouraging unauthorized, harmful, or illegal use of the project against systems without permission.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Violations may result in actions including:

- A private or public warning.
- Removal or editing of inappropriate content.
- Temporary restrictions from project participation.
- Permanent removal from project spaces.

Enforcement decisions will be based on the severity and context of the behavior.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please report it privately to the repository maintainer through the contact information available on the maintainer's GitHub profile.

Reports should include relevant context and links or evidence when available. Sensitive information should not be posted publicly.

## Scope

This Code of Conduct applies to project spaces and to public behavior when it has a meaningful impact on the AuthForge community or project participants.

## Attribution

This Code of Conduct is informed by common open-source community standards and is adapted for the AuthForge project.
